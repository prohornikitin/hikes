Целевой вариант маршрута находиться в архиве **c_авто**. Он подразумевает такси/автобус либо из Питкяранты, либо сразу из Лодейного Поля.
Но если такси/автобус заказать не удасться, или нас не устроит цена, то идем по маршруту **из_питкяранты**

Расшифровка названий треков:
v1 = variant 1 = варинат 1
d1 = day 1 = день 1
p1 = part 1 = часть 1

Файлы можно открыть, например, с помощью сайта [nakarte.me](https://nakarte.me/)
